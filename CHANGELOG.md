# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases follow
[Semantic Versioning](https://semver.org/).

## [1.0.1] - 2026-07-29

### Changed

- Made balanced the default profile for the website, CLI, and Python API.

## [1.0.0] - 2026-07-29

### Added

- Plain browser-based take-ID chirp generator.
- Python CLI for generation, media scanning, take grouping, timing analysis, and NLE exports.
- Safe in-place filename prefixing through `scan --prepend-id`.
- CSV, JSON, FCPXML, and CMX3600 EDL exports.
- Optional microphone listener for checking a recording environment.
- Fast, balanced, and robust chirp profiles, with fast as the default.
